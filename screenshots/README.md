## How to Capture Screenshots

See `SCREENSHOT_INSTRUCTIONS.md` in the root directory for detailed instructions.

## Quick Capture Script

You can use the following approach:

1. Open VSCode/Cursor with the extension loaded
2. Use a Git repository with multiple commits
3. Follow the instructions in `SCREENSHOT_INSTRUCTIONS.md`
4. Use VSCode's built-in screenshot tool or your system's screenshot utility
5. Save screenshots in this directory with the names above

## Recommended Tools

- **macOS**: `Cmd+Shift+4` for area selection, `Cmd+Shift+3` for full screen
- **Windows**: `Win+Shift+S` for Snipping Tool
- **Linux**: `gnome-screenshot` or `scrot`

## Image Requirements

- Format: PNG (preferred) or JPG
- Resolution: Minimum 1280x720, preferably 1920x1080
- File size: Keep under 500KB per image
- Use light theme for better readability
